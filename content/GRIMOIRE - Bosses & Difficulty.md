# Bosses

Boss design leverages the [[GRIMOIRE - Core Mechanics|dual combat system]] to create unique challenges.

---

## Boss Structure

### Multi-Phase Design
- **2–3 phases** per boss
- Each phase has distinct mechanics
- Phase transitions are climactic moments

### Forced Mode Switching
- End of each phase → **Forced return to Action Mode**
- Players cannot cheese phases by staying in turn-based
- Must master both modes to succeed

### Strategic Switching
- Understanding **when** to switch becomes crucial
- Some attacks almost unavoidable in action mode needing switch to turn based (Some player will of course try Action-mode only run or vice versa. They should be technically doable although very hard)
- Some patterns require turn-based precision

## Design Principles

# Difficulty Philosophy

Grimoire targets a specific difficulty sweet spot between two roguelike classics.

---

## Core Philosophy

**Brutal like Isaac**
- High damage
- Tight execution windows
- Punishing mistakes

**Tactical depth like Slay the Spire**
- Planning matters
- Deck composition crucial
- Strategic decision-making

**High Skill Ceiling**
- Expert players can master both modes
- Speedrunning viable
- Multiple paths to victory

---

## Playstyle Support

The game must support players who lean into different styles:

### Action-Focused Players
- Can minimize turn-based time
- Must still understand turn-based for bosses
- Fast, reflex-based gameplay

### Turn-Based-Focused Players
- Can spend more time in tactical mode
- Must still understand action for transitions
- Methodical, calculated gameplay

### Hybrid Players
- Master both modes equally
- Highest skill ceiling
- Most versatile strategies

> [!important] Both Modes Viable
> Neither mode should feel like "the right way" to play. Success comes from understanding both and using them strategically.

---

## Balancing Challenges

**Action Mode Challenges**
- Pattern recognition
- Reflexes and positioning
- Resource management (ammo/reload)

**Turn-Based Challenges**
- Deck management
- Action point optimization
- Enemy priority targeting
- Exit timing decisions

**Mode Switch Challenges**
- Transition timing
- Building advantage states
- Managing [[GRIMOIRE - Word System|deck state]] across modes
