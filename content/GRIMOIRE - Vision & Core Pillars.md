# Core Pillars

## 1. Dual Combat Identity
Both modes are equally viable playstyles.

## 2. Word-as-Weapon System
Deck = arsenal in both modes.

## 3. Genre-Based Archetypes
Each playable character embodies a literary genre.

## 4. Brutal but Tactical
Isaac difficulty + Slay the Spire thinking.

## 5. Exploration Matters
Rogue Legacy 2-style secrets and ability unlocks.

---

# Game Structure

## Run Structure

```
Hub (Story Archive / Lobby)
  ↓
Choose character
  ↓
Begin procedural world
  ↓
First Biome exploration
  ↓
First Biome Boss
  ↓
Repeat for each available biome
  ↓
Final boss
  ↓
Return to hub
```

---

## Hub (Meta Layer)

### Unlockable Content

**New Characters**
- [[GRIMOIRE - Genre System|Different genres]] unlock new playstyles

**New Words**
- Expand the [[GRIMOIRE - Word System|Word pool]]

**New Relic-Style Items**
- Passive effects and build modifiers

**New Zones**
- Via permanent traversal abilities
- Example: Wall breaking
- Secret room access
- Environmental interaction tools

> [!important] No Permanent Stat Upgrades
> Meta progression is horizontal (variety), not vertical (power).
